# 교실 공기와 집중도 분석

환기가 부족한 실내 공간에서 CO2, 온도, 습도, 미세먼지 같은 환경 요인이 졸림과 학업 집중도에 어떤 영향을 줄 수 있는지 살펴보는 데이터과학 수행평가 프로젝트입니다.

## 바로 보기

- 웹사이트: `site/index.html`
- 정리 데이터: `data/processed/indoor_air_quality_subway_standard.csv`
- 교실 조사 양식: `data/processed/classroom_focus_survey_template.csv`

## 핵심 결론

공개 실내공기질 데이터에는 CO2, 미세먼지, VOC 등 환경 변수는 있지만 학생 집중도 점수는 포함되어 있지 않습니다. 따라서 공개 CSV만으로 CO2와 학업 집중도의 직접 상관관계를 증명할 수는 없습니다.

다만 KCI 논문은 교실 CO2 농도 상승과 집중력 검사 저하, 문제풀이 실수 증가, 출석률 감소가 함께 나타난 선행연구를 정리하고 있습니다. 따라서 이 프로젝트는 공개 실내공기질 데이터 분석과 논문 근거를 결합해, 실제 교실에서 CO2와 집중도 설문을 함께 수집하는 후속 조사 설계를 제안합니다.
